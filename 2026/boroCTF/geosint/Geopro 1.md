# Description

> Find the city this image was taken in.
>
> flag format: boroCTF{city_name}
> (Replace any space with an underscore)

[geosint.png](../_assets/geosint.png)

# Solution

Just using [Google Images](https://images.google.com/) shows the building is Lakshmi Vilas Palace in Vadodara, Gujarat, India.
The flag was `boroCTF{Vadodara}`.
